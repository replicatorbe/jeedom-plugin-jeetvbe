# Jeedom TV (`jeetvbe`)

Plugin Jeedom qui expose à une application Android TV des pages de tuiles
(lumières, volets, consignes, températures, scénarios), pilotables à la
télécommande. Le contrat d'API entre le plugin et l'application est
[`docs/api.md`](docs/api.md) : il fait foi pour les deux côtés.
